# Network Intrusion Detection

## Overview
This project focuses on building a **Network Intrusion Detection System (NIDS)** using machine learning techniques. The goal is to classify network traffic into normal and attack categories using the **NSL-KDD dataset**.

## Dataset
The dataset used in this project is **NSL-KDD**, a refined version of the KDD99 dataset, which is commonly used for intrusion detection research.

🔗 **Download Dataset:** [NSL-KDD Dataset](https://drive.google.com/file/d/1G5CDPNClaGGgUK6j7gHWB606nxpaTj17/view?usp=drive_link)

## Features & Techniques
- **Data Preprocessing**: Cleaning and transforming raw data for model training.
- **Feature Engineering**: Selecting and extracting relevant features.
- **Machine Learning Models**: Implemented various models for intrusion detection.
- **Evaluation Metrics**: Used accuracy, precision, recall, and F1-score for assessment.

## Installation
To set up the project, run the following commands:
```bash
# Clone the repository
git clone https://github.com/neel5682/Network-Intrusion-Detection.git
cd Network-Intrusion-Detection

# Install dependencies
pip install -r requirements.txt
```

## Usage
Run the model training script:
```bash
python train_model.py
```
